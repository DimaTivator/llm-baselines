Регуляризация реализована для `AdamW` как отдельный оптимизатор `AdamWSpectralL1Reg` в файле `src/optim/adamw_spectral_L1_reg.py`. Это связано с тем, что для ее применения нужны веса до основного обновления оптимизатором, то есть нужно лезть в цикл обновления параметров. Возможно, что это можно сделать как-то умнее через какой-нибудь callback, но я не изучал этот вопрос

Для применения этой регуляризации нужно при запуске выбрать `--opt "adamw-spectral-l1-reg"`, коэффициент регуляризации регулируется через задание аргумента `--spectral_l1_reg_coef` (по умлочанию используется 0.1)

Еще из файлов добавил два скрипта файла `scripts/train_fineweb_adamw.sh` и `scripts/train_fineweb_dmuon.sh` как пример параметров, с которыми я делал предварительные запуски на fineweb
